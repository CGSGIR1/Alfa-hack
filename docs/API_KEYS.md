# Ключ API

EmbeddingGemma считает векторы локально. Разметка и генерация отчётов работают
через API организаторов; их веса не включаются в образ.

## Настройка

Скопируйте `.env.example` в `.env` рядом с Compose и заполните `LLM_API_KEY`.
Адрес и названия моделей должны соответствовать доступу вашей команды:

```dotenv
LLM_BASE_URL=https://changellenge.up.railway.app/v1
LLM_API_KEY=YOUR_TEAM_KEY
LLM_MODEL_MAIN=deepseek/deepseek-v4.1-flash
LLM_MODEL_FAST=qwen/qwen3.6-35b-a3b
LLM_MODEL_SECOND=z-ai/glm-5.3-flash
LLM_MODEL_QUERIES=
LLM_MODEL_CRITIC=
PIPELINE_AUTO_POLL=1
APP_PORT=8765
APP_IMAGE=ghcr.io/rastok314/alfa-hack-public:1.1.0
```

При пустом `LLM_MODEL_QUERIES` используется основная модель, при пустом
`LLM_MODEL_CRITIC` — вторая. Compose полного образа переопределяет пути к Gemma
и CSV на Linux-пути внутри контейнера.

Проверка FAST-модели с коротким реальным запросом:

```sh
docker compose -f compose.bundled.yaml run --rm app check --llm
```

Она выводит результат и статистику, не ключ. Проверка FAST не подтверждает весь
многоагентный отчёт; его проверяют отдельно с одной компанией и одной новостью.

После изменения `.env`: `docker compose -f compose.bundled.yaml up -d --force-recreate`.
Локальный сервер перезапускается через `restart_interface.cmd`.

## Передача

Передаются образ, инструкция и пустой шаблон `.env.example`. Получатель вводит
свой выданный ключ. Общий командный ключ передают отдельно, согласованным командой
способом. В этой поставке действующий ключ не включается в Git, архив исходников,
Dockerfile, Docker-слои или документацию.

`--env-file` передаёт ключ при запуске. Он не становится частью образа, но доступен
администратору Docker. Не упаковывайте настроенный контейнер через `docker commit`.
Не публикуйте `.env`, `docker inspect` рабочего контейнера и непроверенные логи.
Если ключ попал в историю Git, его нужно отозвать у провайдера.

| Ошибка | Что проверить |
| --- | --- |
| 401/403 | Ключ, адрес API и разрешения на модель |
| Модель не найдена | Точное имя из инструкции организаторов |
| Бюджет исчерпан | Лимит ключа у провайдера |
| 429/5xx/таймаут | Доступность API; очередь применяет ограниченные повторы |
| Нет новых карточек | Выбор компании, автоматика, пауза API, пороги и поддерживающая аналитика |

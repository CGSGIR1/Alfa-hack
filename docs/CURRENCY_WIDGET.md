# Курсы валют на главной странице

Виджет «Конвертация» показывает справочные курсы покупки и продажи **наличной**
валюты Альфа-Банка (USD новых серий, EUR, CNY), а не курсы ЦБ и не персональные
курсы корпоративного счёта. Источник: https://alfabank.ru/currency/.
Фактическая конвертация денег в приложении не выполняется.

Используется тот же публичный запрос, что на странице банка:
`https://alfabank.ru/api/v1/scrooge/currencies/alfa-rates`.
Фильтры: `clientType.eq=standardCC`, `segmentType.eq=none`,
`rateType.in=rateCass`, `currencyCode.in=CNY,EUR,USD`,
`lastActualForDate.eq=true`, `date.lte=<текущее время UTC>`.
`buy` банка отображается как «Продать» для клиента; `sell` — как «Купить».
При наличии `valueWithCoefficient` используется опубликованное значение с
коэффициентом, иначе `originalValue`. Типы карт/онлайн и другие сегменты не смешиваются.

Браузер обращается к локальному `/api/currency-rates` раз в минуту, независимо
от выбранной компании, очереди отчётов и LLM. Первый запрос запускает фоновую
загрузку; пока она идёт, браузер проверяет готовность раз в 2 секунды.
Скрытая вкладка приостанавливает опрос, при возвращении обновляет данные.
Сервер держит общий для пользователей кэш `runtime/cache/alfa-currency.json`.
Сетевые запросы ограничены по времени; параллельные обращения не запускают
повторную загрузку. Сбой банка не блокирует интерфейс и обработку новостей.

Показывается время **действия курса**, полученное от банка, в московском часовом
поясе. В подсказке под виджетом — время проверки. Это разные времена:
в выходные банк может вернуть действующий курс, установленный в пятницу.
При ошибке остаются последние полученные курсы с явной отметкой; через
24 часа без успешной проверки вместо значений отображается «—».
Демо-курсы и значения ЦБ в качестве замены не используются.

TLS проверяется с локальной копией корневого сертификата Минцифры, скачанной
по HTTPS с официального CDN Госуслуг. Эта настройка применяется только к
фиксированному адресу банка; перенаправления на другой адрес запрещены. ОС, браузер и
настройки доступа к LLM не меняются. Происхождение и контрольная сумма:
`src/integration/certs/README.md`.

После обновления кода работающий сервер нужно перезапустить обычным способом.
Ключ API и отдельные настройки для курсов не требуются.

Проверки: `python -m unittest discover -s tests -p test_currency.py`,
`node tests/test_currency_widget.cjs`; HTTP-подключение виджета также проверяется
общим интеграционным набором. Тестовый JSON — реальный публичный ответ банка
от 25.10.2026, сохранённый в `tests/fixtures/currency/alfa-cash.json`.

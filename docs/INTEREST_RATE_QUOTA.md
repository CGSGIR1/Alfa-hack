# Ограничение новостей о процентных ставках — 26 октября 2026

Прежняя идентификация финансовых событий распознавала только подтверждённые
решения ЦБ с конкретной датой и значением ставки. Прогнозы, комментарии и
реакции бизнеса оставались отдельными событиями, хотя отображались с общей
меткой «Процентные ставки». Поэтому одной проверки перепечаток было недостаточно.

Теперь для каждой компании допускается не более одного такого материала за
12 часов. Интервал скользящий, от фактического завершения обработки, а не от
полуночи или даты исходной публикации. Параметр в config.json:

```json
"admission": {
  "min_weak_news_score": 0.45,
  "interest_rate_interval_hours": 12
}
```

Перед генерацией проверяются метка, исходная разметка секторов и явные заголовки
о ключевой ставке/решениях ЦБ. При наличии итогового topic он соответствует метке
на сайте. Отдельная повторная LLM-классификация не вызывается. Если модель впервые
назначила эту метку только в готовом отчёте, результат также учитывается в квоте.
Нельзя заранее гарантировать будущую метку модели у неразмеченного материала.

Проверка действует для автоматики, ручных партий и завершения старого отложенного
пакета. В ручной партии не может быть сразу нескольких материалов о ставках.
После успешной обработки, включая аргументированное отклонение LLM, следующие
материалы этой темы откладываются. Ошибки API продолжают использовать отдельный
ограниченный механизм повторов. Другие темы и другие компании не блокируются.
Разметка общего новостного корпуса продолжается: это ограничение персональных
отчётов, а не остановка парсера или предварительной разметки новостей.

Основание квоты — сохранённые снимки завершённых отчётов. Изменение профиля,
удаление исходной статьи, архивирование отчётов и перезапуск не сбрасывают её.
Новых таблиц, массовой миграции JSON и удаления старых отчётов не требуется.

Лента объединяет уже накопленные материалы с этой меткой внутри 12-часового
интервала. Остаётся последний доставленный текст со стабильным ID карточки,
а прежние материалы сохраняются в истории. Это квота по теме, а не утверждение,
что все статьи являются точными копиями. Через 12 часов может появиться новая
карточка; бессрочное хранение означает, что карточки разных интервалов остаются.
Правило охватывает и аналитические сценарии с той же отображаемой меткой.

Проверка на копии текущих данных: U_16802, семь сохранённых материалов о ставках
в одном интервале → одна карточка с последним отчётом. Основная БД не изменялась.
Регрессионные тесты не вызывают платный API и проверяют лимит, повторный запуск,
истечение 12 часов, независимость компаний, старые партии и сохранность архива.

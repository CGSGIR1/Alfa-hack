# Откат эксперимента с признаками событий

24 октября 2026 года, по просьбе пользователя.

## Рабочее состояние

Основная база остаётся по пути `runtime/news-analytics.db`. Восстановлена копия `runtime/backups/news-analytics.20261024T172033153267Z.db`, сделанная до изменений для эксперимента. Все 642 старых JSON восстановлены из резервных ZIP, а не заново сформированы моделью.

В рабочей базе и JSON отсутствует `event_identity`. Таблица `news_event_identities` не создаётся при обычном запуске. Подготовка новых публикаций снова использует промпт `news-two-views-1.0/p2`. Команды `enrich-events`, `backfill-events` и `compare-events` убраны из рабочего интерфейса.

При импорте старой экспериментальной копии поле `event_identity` игнорируется. Это предотвращает случайное повторное добавление признаков и изменение хешей из-за этого поля.

Обновление агентов отчёта (`report_mode=deep`), интерфейс и поддержка рыночных показателей сохранены. Они относятся к отдельной задаче. Обычный поиск компании, новостей и аналитики и прежние правила обработки повторов сохранены.

## Где сохранены изменённые версии

`runtime/archived-event-dedup/20261024-212325/`:

- `news-analytics-with-event-features.db` — изменённая основная база, перенесённая перед восстановлением.
- `enriched-json-before-rollback.zip` — изменённые рабочие JSON до отката.
- `news-event-enriched/` — отдельные дополненные копии JSON.
- `code-before-rollback.zip` — затронутые исходники и проверки до отката.
- `manifest.json` — выбранная резервная копия, контрольные суммы и результаты проверки.

Исходные резервные архивы JSON сохранены в `runtime/event-backfill/20261024T174722741822Z/original-json.zip` и `runtime/event-backfill/20261024T174821946184Z/original-json.zip` (8 и 633 файла). Ещё одна исходная копия взята из `runtime/event-backfill/20261024T174821946184Z/additional-original-copies.zip`. Итого восстановлены все 642 документа. Перед записью проверены ID, отсутствие экспериментального поля и совпадение хешей с резервной базой.

Отчёт и результаты эксперимента оставлены в `experiments/event-dedup-2026-10-24/` как исторические материалы, не как текущая рабочая база.

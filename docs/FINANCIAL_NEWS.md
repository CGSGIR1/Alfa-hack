# Обновляемые карточки ставки и курсов

Новости проходят прежний поиск компании и аналитики, без финансовой квоты.
Дополнительные правила работают только для уверенно распознанных фактических
сообщений о решении Банка России и официальных/рыночных курсах USD, EUR, CNY.
Прогнозы, комментарии и неоднозначные заголовки не отсекаются этими правилами.

- Ставка: отдельная карточка каждого заседания/даты решения ЦБ. Перепечатка
  того же значения в тот же день не создаёт новый итоговый отчёт. Исправление
  значения может обновить карточку; следующее решение имеет другую карточку.
- Курсы: одна карточка на валюту и тип курса. Официальный курс и рыночная
  котировка не смешиваются. Новое значение/дата действия проходит обычную
  оценку и после успешного отчёта обновляет карточку с тем же `feed_id`.
- В начальном накопленном пуле выбирается наиболее свежий допущенный курс
  этой валюты/типа, чтобы не обрабатывать подряд все старые ежедневные значения.
- Совпадение проверяется по исходным первым абзацам, дате действия и уровню,
  а не по векторам общего макроэкономического механизма. У официальных курсов
  учитываются округлённые перепечатки. Без даты/значения подавлять LLM нельзя.
- Память завершённых оценок, включая отклонения LLM, читается из постоянных
  снимков отчётов. Удаление исходной статьи через десять дней не стирает её.
  При изменении профиля компании применяется новая ревизия оценки.
- Точные перепечатки, распознанные до разметки, не отправляются на разметку
  снова. Для дополнительного источника сохраняется библиографическая ссылка
  в `financial_event_sources` без ещё одной копии полного текста статьи.
- Обновление карточки происходит сразу после нового итогового отчёта. Повторная
  отметка «непрочитано» для валютной карточки — не чаще одного раза в 12 часов
  (`NOTIFICATION_HOURS` в `src/integration/financial_events.py`). Это ограничение
  уведомления, а не запрет получения более свежих данных. Перепечатки сами
  по себе отметку не возобновляют. Отдельных push-уведомлений браузера нет.

Основные части: `financial_events.py` — признаки и история; `events.py` —
фильтр и объединение; `service.py` — исключение платных повторов; `site.py`
— проекция сохранённых отчётов; клиент сохраняет прочитанную версию карточки.
Очередь старой подготовленной партии также проверяется перед возобновлением.

Это намеренно узкие правила: неподтверждённые и сложные составные события
остаются в обычном отборе. Дедупликация всех новостей по эмбеддингам не включена.

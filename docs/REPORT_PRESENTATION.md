# Оформление отчёта в интерфейсе

Этот компонент полного отчёта теперь находится в web_static/manage/ и
доступен через /manage. Главный сайт использует исходное оформление
index (6).html из папки «финал»; его интеграция описана в SITE_INTEGRATION.md.

Обновление 25.10.2026: главная карточка использует short_title, краткий
brief.takeaway, пояснение impact.explanation и рекомендации. Длинные выводы
и источники доступны через вкладки. /manage также поддерживает эти поля,
сохраняя совместимость со старыми отчётами. Подробности переноса и проверок:
[FINAL_UI_REPORTS_2026-10-25.md](FINAL_UI_REPORTS_2026-10-25.md).

Используются сохранённый company-analysis-report-1.1 и пакет источников той же
партии (report-generation-input-1.1). Отображение не вызывает LLM, не меняет
порогов поиска и не пересчитывает оценку влияния в браузере.

Сверху — сводка по компании, дата отчёта, число принятых и отклонённых новостей.
Каждая принятая новость получает карточку с заголовком источника, кратким фактом,
ссылкой и оценкой применимости из LLM. Условность не превращается в вероятность.

Вкладки карточки:

- «Для компании»: значение, риски, возможности, условия. Действия и недостающие
  данные раскрываются отдельно, без удаления текста из сохранённого отчёта.
- «Новость»: факты в изложении отчёта, дата и ссылка на публикацию, исходные
  абзацы. Тезисы после подготовки отмечены отдельно. При неполных исходниках
  показано предупреждение; полная статья не подменяется выбранными абзацами.
- «Аналитика»: цитируемые механизмы, условия применимости, дата и издатель,
  точные цитаты и страницы. Полные исходные фрагменты раскрываются отдельно,
  одинаковые фрагменты показываются один раз в пределах карточки.
- «Основания и ограничения»: причины отбора, известные факты профиля,
  недостающие сведения. Косинусы и сведения о ветвях поиска скрыты в раскрытии
  «Как сработал поиск» и не используются как уверенность во влиянии.

Оценки авторов аналитики и выводы ИИ имеют разные подписи. Пометка материалов
организаторов ставится по provided_by_organizer=true. Независимый контекст
компании показан отдельно от объяснения конкретной новости. Отклонённые и
фоновые материалы свёрнуты, причины доступны читателю.

Новый завершённый фоновый отчёт подхватывается открытой страницей. При смене
компании предыдущий отчёт убирается. История содержит компактные записи с
кнопкой открытия. JSON и пакет для LLM находятся в меню скачивания.

Для вкладок предусмотрены aria-selected, aria-controls, управление стрелками,
Home/End; для узкого экрана — горизонтальная прокрутка заголовков. Текст
источников выводится через textContent, ссылки ограничены HTTP/HTTPS.

# Модуль новостной аналитики

В поставке 1.1.0 используйте корневой `app.py` и [основной README](../README.md).
Код модуля вызывается интеграционным слоем; отдельный сервер модуля не нужен.

Подготовленные входы расположены в `../private-data/companies`, `news` и
`analytics`. Папка и CSV хранятся только в приватном репозитории. В публичном
Docker-образе нет этих входов или исходных PDF. Для обычной работы достаточно
валидированных JSON аналитики с исходными текстами и цитатами.

Для проверки самостоятельного модуля из этой папки:

```sh
python -m unittest discover -s tests -p "test_*.py" -v
python tools/validate_inputs.py
```

Первая команда использует тестовые примеры и подставную модель. Вторая проверяет
подготовленные JSON и их импорт в временную БД, без API и PDF. Параметр
`--verify-pdfs` включает дополнительную проверку оригиналов, если они отдельно
предоставлены по путям из метаданных.

Источники и лицензии описаны в [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).

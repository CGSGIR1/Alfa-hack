# Закрытые материалы организаторов

Эта папка хранится только в приватном репозитории. Не публикуйте её содержимое,
включая подготовленные JSON с текстами аналитики и фактами о компаниях.

- `csv/`: три исходные таблицы компаний, платежей и связей.
- `companies/`: 10 подготовленных профилей.
- `analytics/`: 22 документа аналитики в JSON с исходными текстами и цитатами.
- `news/`: 614 подготовленных новостей начального корпуса.
- `startup/news-analytics.db`: чистая SQLite-база с 10 профилями и 4 реальными
  завершёнными отчётами. От 25 октября 2026 года: у `U_106783` две карточки,
  у `U_9250` одна. От 26 октября 2026 года: у `U_14366` отчёт из пяти новостей,
  три из них показаны карточками. Исходных новостей, готовых векторов, ключей, незавершённых
  задач и истории старого сервера в этой базе нет.

Оригинальные PDF не требуются для запуска по этим JSON и не входят в комплект.
Исходные контрольные суммы PDF сохранены в метаданных аналитики для происхождения.
`manifest.json` фиксирует контрольные суммы переданных файлов.

Оставьте папку рядом с `compose.bundled.yaml`. Название и расположение внешней
папки проекта произвольны. Контейнер подключает `private-data` только для чтения;
рабочая база, новые профили и отчёты записываются отдельно в `runtime`.
Compose копирует стартовую базу в `runtime/news-analytics.db` только при её
отсутствии. Существующая база не заменяется. База остаётся исключительно в приватном репозитории и не попадает в образ.

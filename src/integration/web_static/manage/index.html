Автоматическая обработка

01

Компания

Выберите компанию из базы или загрузите её JSON ниже.

Поиск новостей за последние 7 дней до выбранной даты.

До 10 кандидатов в каждой ветвиДля каждой новости ищем аналитику по механизмам и исходным фрагментам. Сначала показываем пересечение.

Уже проверенные новости повторно не сравниваются. Если партия ожидает ответа LLM, откроется тот же пакет.

Обновление новостей

Собрать и подготовить свежие публикации для общей базы. Отчёт создаётся отдельно для выбранной выше компании.

В автоматическом режиме отчёт обновляется только для выбранной компании. Операция использует API организаторов.

03

Готовый отчёт

Сохраните JSON ответа итоговой LLM. Он появится в истории компании и завершит обработку партии.

02

Добавить материалы

JSON аналитики, новостей или компаний. Тип определится автоматически.

    Можно выбрать несколько файлов разных типов. Материалы с тем же ID обновляются; перед изменениями сохраняется копия базы.
